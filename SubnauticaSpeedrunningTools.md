# Subnautica Speedrunning Tools and Helpers

This Indexes the Tools used for Timing, Automating, Tracking and Helping Speedrun Subnautica.

# Stand Alone Apps

## 1. LiveSplit

[LiveSplit](https://livesplit.org/) is a Sleek and Highly Customizable Timer Program for Speedrunners that is Both Easy to use and Full of Features. It Supports Custom Plugin Components aswell.

## 2. Subnautica Launcher

[Subnautica Launcher](https://github.com/ItsFrostyYo/Subnautica-Launcher/releases) is a Windows launcher for installing, organizing, switching, and launching multiple versions of Subnautica, Subnautica: Below Zero and Subnautica 2, with Speedrun Tools easy to access.

# Specific Livesplit Components



## 1. Subnautica Autosplitter

[Sprinter31/Subnautica_Autosplitter](https://github.com/Sprinter31/Subnautica_Autosplitter/tree/LiveSplit.Subnautica)
The Subnautica Autosplitter is a Livesplit Component by 'Sprinter31' which allows for a Fully Customized Automatic Timing Experience. It allows for Auto Starting the Timer, Automatic Splits which are Fully Customizable with Prefabricated Splits or Conditions, and allows for Automatic Resetting. It also is bundled with the Explosion Timer for showing the Explosion Time of the Active Save File/Run.

### How to use

1. Open LiveSplit
2. Right-click → Edit Splits
3. Set *Game Name* to Subnautica
4. Activate the Auto Splitter
5. Open Settings and configure split options



### Updated Subnautica Autosplitter Fork

[ItsFrostyYo/Subnautica_Autosplitter](https://github.com/ItsFrostyYo/Subnautica_Autosplitter/tree/LiveSplit.Subnautica)
An Updated Fork of the Original Subnautica Autosplitter by 'ItsFrostiSR' which contains Updates for Various Features aswell as adding Native Support for the December 2021 Version, and runs on its own Independent Updating from the Original.

#### How to Install Custom Fork Version

1. Close LiveSplit.
2. Download the Required [Component DLL](https://raw.githubusercontent.com/ItsFrostyYo/Subnautica_Autosplitter/LiveSplit.Subnautica/Components/LiveSplit.Subnautica.dll).
3. Place the DLL in LiveSplit's `Components` folder replacing the original Subnautica Autosplitter.
4. It should show up in place of the original Subnautica Autosplitter, or if it does not you can add or Configure the Component from the Appropriate Layout Category.



## 2. Subnautica Explosion Timer

[Sprinter31/SubnauticaShipExplosionInfo.dll](https://github.com/Sprinter31/Subnautica_Autosplitter/blob/LiveSplit.Subnautica/SubnauticaShipExplosionInfo.dll)
The Explosion Timer/Ship Explosion info is a Livesplit Component originally built by 'Meeperty' that display the active Subnautica Aurora Explosion Time Information to display what time between 46:00->1:19:59 in the Ggames Time it will Explode, Its Suggested to use this Directly Through the Autosplitter rather then a Stand Alone Component for Small Fixes and Easier Toggle.

### How to use

1. Open LiveSplit
2. Right-click → Edit Splits
3. Set *Game Name* to Subnautica
4. Activate the Auto Splitter
5. Open Settings and click "Add Explosion Time" or "Remove Explosion Time"
6. or you can get the [Component DLL](https://raw.githubusercontent.com/ItsFrostyYo/Subnautica_Autosplitter/LiveSplit.Subnautica/SubnauticaShipExplosionInfo.dll) Directly.



## 3. Subnautica Progression Tracker

[ItsFrostyYo/LiveSplit.SubnauticaTracker](https://github.com/ItsFrostyYo/Subnautica_Autosplitter/tree/LiveSplit.Subnautica/Livesplit.SubnauticaTracker) 
The Subnautica Tracker is a Customizable Livesplit Component by 'ItsFrostiSR' that Displays the Progress Towards 100% Completion or Configured Completion in the Active Save File/Run and also allows for Checking for Missing Databanks, Blueprints and Achivements towards 100%.

### How to Install

1. Close LiveSplit.
2. Download the Required [Component DLL](https://raw.githubusercontent.com/ItsFrostyYo/Subnautica_Autosplitter/LiveSplit.Subnautica/Components/LiveSplit.SubnauticaTracker.dll).
3. Place the DLL in LiveSplit's `Components` folder replacing the original Subnautica Autosplitter.
4. Open Livesplit
5. Right-click → Edit Layout
6. Press the + Button and add "Subnautica Tracker" from the Information Section.



## 4. Subnautica Reset Macro

[LiveSplit.SubnauticaMarco](https://github.com/ItsFrostyYo/Subnautica_Autosplitter/tree/LiveSplit.Subnautica/Livesplit.SubnauticaMarco)
Fully Configurable Livesplit Component Subnautica Macro for Faster and Automated Resetting for Speedrunning. Supports Vanilla Subnautica UI for 2018, 2021, 2023 and 2025 Versions, Allows all 4 Normal Base Gamemodes, also has support for Subnautica Speedrunning Mod's BetterRNG Specific Custom Gamemodes UI, and its Hardcore Modes Custom Quit Button. The Reset Macro also allows for Explosion Time Resetting that runs either Until it finds a Suitable Explosion Time within the Set Range or you Abort using the Reset Button Again.

### How to Install

1. Close LiveSplit.
2. Download the Required [Component DLL](https://raw.githubusercontent.com/ItsFrostyYo/Subnautica_Autosplitter/LiveSplit.Subnautica/Components/LiveSplit.SubnauticaMarco.dll).
3. Place the DLL in LiveSplit's `Components` folder replacing the original Subnautica Autosplitter.
4. Open Livesplit
5. Right-click → Edit Layout
6. Press the + Button and add "Subnautica Reset Macro" from the Control Section.
